Comandos que usa cualquiera de los dos antes de empezar a tocar
Siempre antes de editar algo:
cd "$env:USERPROFILE\Desktop\ARDE Tickets"
git checkout codex/build-arde-event-management-platform
git pull origin codex/build-arde-event-management-platform

Eso trae lo último que haya subido el otro.

Cuando uno termina de modificar algo

Después de editar en VSCode, guardar y probar, hace:

cd "$env:USERPROFILE\Desktop\ARDE Tickets"
git status
git add .
git commit -m "Describe los cambios realizados"
git push origin codex/build-arde-event-management-platform

Ejemplo:

git commit -m "Mejora formulario de eventos"
